Create a polished bilingual static website for Firefly Entertainment using the existing Firefly brand identity and logo.

The website must have a minimalist landing page first:

- White background with very light gray secondary areas
- Centered Firefly logo only
- One short, memorable, premium tagline beneath the logo
- Below the tagline, show two clear language choices: “English” and “中文”
- No navigation menu, no extra sections, no stock photos, and no unnecessary decoration on the landing page
- The language choice should lead to the corresponding English or Simplified Chinese version of the website
- Support direct routes such as /en and /zh

Visual direction:

- Restrained, minimal, modern, refined, and premium
- Use dark charcoal text on white and light gray surfaces
- Use one primary accent color sampled from the existing Firefly logo, preferably the violet-purple area
- Use the logo’s blue-to-violet-to-magenta gradient only in very limited details, such as a small hover effect or fine accent line
- Do not use a dark background as the main website theme
- Do not redraw, modify, or replace the existing logo

After the language selection, create a concise company introduction website with:

- About Firefly Entertainment
- What We Do
- Our Approach
- Contact
- Contact email: david@fireflyentertainment.net
- A subtle language switcher on the internal pages
- Responsive mobile-first layout
- Fast static-page performance
- Basic SEO metadata and Open Graph metadata

For the tagline, propose three concise English options with natural Simplified Chinese translations. Use “FUN AND BRANDED” only as an existing brand descriptor, not automatically as the final tagline.

Do not invent clients, artists, awards, statistics, testimonials, offices, certifications, or business claims. Use clearly marked placeholders for any unapproved images or content.

Start in Plan mode. Show the proposed landing page, sitemap, visual system, and three tagline options before building anything.
